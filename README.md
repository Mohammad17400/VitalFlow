# VitalFlow — React + Tailwind CSS Healthcare Website

A complete multi-page healthcare website inspired by the VitalFlow Framer template.

## Pages
- **Home** — animated hero with floating cards, appointment search widget, stats, "Why us", services preview, testimonial marquee, CTA
- **Services** — 6 service cards with hover effects
- **Doctors** — team grid with image hover overlays + testimonials
- **Contact** — info cards, working form (front-end), embedded map

## Features
- Smooth page transitions & scroll-reveal animations
- Sticky glass navbar with scroll effect + mobile menu
- Hover effects on every button, card and image
- Testimonials auto-scrolling marquee (pauses on hover)
- Fully responsive

## Run it
```bash
npm install
npm run dev
```
Then open http://localhost:3000 (or the port Vite shows).

## Build for production
```bash
npm run build
```
